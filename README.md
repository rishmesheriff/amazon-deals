# Amazon Deals

A mobile-first Amazon deal discovery site for discounts of 15% or more.

## Included

- Searchable, filterable product discovery
- 15%, 25%, and 50% savings tiers
- Dedicated product detail pages and affiliate-link integration point
- Saved-deal persistence for signed-in users
- Alert, profile, policy, privacy, and terms experiences
- SEO metadata, product schema, sitemap, and responsive layouts

## Live site

https://amazon-deals-finder.rishmesheriff.chatgpt.site

## Configuration

Set `NEXT_PUBLIC_AMAZON_ASSOCIATE_TAG` before enabling live affiliate links. The current catalog uses demonstration listings until approved Amazon Product Advertising API credentials are configured.
